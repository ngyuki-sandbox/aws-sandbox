# Amazon ECR と Docker Buildx によるビルドキャッシュ高速化

Amazon ECR をキャッシュバックエンドとして使用し、Docker Buildx の `--cache-from` および `--cache-to` オプションでコンテナイメージのビルドを高速化するサンプルです。

## 概要

CI/CD 環境（GitHub Actions や AWS CodeBuild など）では、ビルド実行ごとにホスト環境が破棄されるため、
ローカルの Docker レイヤーキャッシュが維持されず、毎回フルビルドが発生して時間がかかってしまう課題があります。

Docker Buildx の `type=registry` キャッシュバックエンドを利用すると、ビルドキャッシュをリモートのコンテナレジストリにエクスポート・インポートできます。
これにより、エフェメラルな CI/CD 環境でもキャッシュヒットによる大幅なビルド時間短縮が実現できます。

## 主なポイント

- **レジストリキャッシュバックエンド (`type=registry`)**
  ビルドレイヤーのキャッシュを ECR リポジトリ上の指定タグ（例: `:cache`）に保存・取得します

- **キャッシュモード (`mode=max`)**
  デフォルトの `mode=min` では最終ステージのレイヤーのみがキャッシュされますが、`mode=max` を指定することでマルチステージビルドの中間ステージレイヤーもすべてキャッシュ対象になります

- **ECR 互換性オプション (`image-manifest=true`)**
  ECR でキャッシュマニフェストを適切に保存するために、Image Manifest 形式で出力するオプションを指定します

- **イミュータブルタグの無効化 (`image_tag_mutability = "MUTABLE"`)**
  同じキャッシュタグ（例: `:cache`）をビルドごとに更新して上書きするため、ECR リポジトリはタグ変更可能（MUTABLE）である必要があります

- **Buildx ドライバ (`docker-container`)**
  デフォルトの `docker` ドライバでは外部レジストリへのキャッシュエクスポートが制限される場合があるため、BuildKit コンテナを起動する `docker-container` ドライバを使用します

- **イメージインデックス作成の抑止 (`--provenance=false`)**
  Buildx（BuildKit）はデフォルトで SLSA プロベナンス（アテステーション）を生成してイメージに添付するため、単一アーキテクチャのビルドであっても Image Index（マニフェストリスト）形式でプッシュされます。イメージインデックスを生成せず、単一の Image Manifest として ECR へプッシュしたい場合は `--provenance=false` を指定します

## なぜ `type=inline` ではダメなのか？

Docker にはイメージ自体にキャッシュメタデータを埋め込む `type=inline` も存在しますが、以下の理由から実運用（特にマルチステージビルド）では不十分であり、`type=registry` を採用する必要があります。

- **中間ステージのキャッシュを保存できない（`mode=max` 非対応）**
  `type=inline` は最終成果物のイメージ設定 JSON にキャッシュメタデータを埋め込む仕組みのため、最終イメージに含まれない中間ビルドステージ（`builder` ステージなど）のレイヤーキャッシュを保存できません（`mode=min` 相当のみ動作）。そのため、重い依存関係のインストールやコンパイル処理を行うマルチステージビルドではキャッシュが効かず、ビルド時間の短縮効果が得られません

- **本番イメージへの不要なメタデータの混入**
  `type=inline` では本番環境にデプロイするコンテナイメージ自体にキャッシュ情報が直接書き込まれるため、イメージサイズが無駄に肥大化し、不要なビルド履歴情報が成果物に含まれてしまいます。`type=registry` であれば、成果物イメージ（`:latest`）とキャッシュ（`:cache`）を完全に分離できます

- **キャッシュのライフサイクル管理が困難**
  `type=registry` であれば、キャッシュ専用のタグ（`:cache`）として ECR に保存できるため、ECR のライフサイクルポリシー等を用いて「古いキャッシュの自動破棄」や「キャッシュのみのパージ」が柔軟に行えます
