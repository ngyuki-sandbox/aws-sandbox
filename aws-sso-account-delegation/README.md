# IAM Identity Center で割り当て可能なアカウントを許可セットごとに制御する

次のようにアカウントがあるときに、

- account-A1
- account-A2
- account-B1
- account-B2
- account-C1
- account-C2

これらに許可セットを割り当て可能なユーザーを次のように制御する

- user-A
    - account-A1
    - account-A2
- user-B
    - account-B1
    - account-B2
- user-C
    - account-C1
    - account-C2
