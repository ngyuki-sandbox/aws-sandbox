# AWS Backup のクロスアカウントコピー

1 つの EC2 インスタンスを AWS Backup でバックアップし、別の AWS アカウントにある次の 2 種類のボールトへコピーするサンプルです。

- Vault Lock を設定した標準バックアップボールト
- 論理的にエアギャップされたボールト

## 前提条件

- 2 つの AWS アカウントが同じ AWS Organizations 組織に所属していること
- 組織の管理アカウントで AWS Backup のクロスアカウントバックアップが有効になっていること
- クロスアカウントコピーと論理的にエアギャップされたボールトの両方に対応したリージョンを使用すること

## 暗号化

EC2/EBS などの AWS Backup の完全管理サービスではないリソースのバックアップのクロスアカウントコピーにはいくつかの制約があります。
なお、S3 や DynamodB のような AWS Backup の完全管理のサービスのリソースは無関係です。

### 標準ボールトの KMS キー

標準ボールトへのクロスアカウントコピーには、カスタマーマネージドキーが必要です。
AWS マネージドキーポリシーはイミュータブルであり、クロスアカウントを共有できないためです。
AWS Backup が完全管理するリソースでは、コピー先に AWS 管理キーの `aws/backup` を使用できる場合がありますが、EC2 はその対象外です。

> [クロスアカウントコピーの公式ガイド](https://docs.aws.amazon.com/aws-backup/latest/devguide/create-cross-account-backup.html)

### 論理的エアギャップボールトのキー

論理的エアギャップボールトは、バックアップの実体を AWS Backup サービス所有のアカウントに保存します。
キーを指定しない場合は AWS 所有キーで暗号化されるため、利用者側のカスタマーマネージドキーは必須ではありません。

> [論理的エアギャップボールトの公式ガイド](https://docs.aws.amazon.com/aws-backup/latest/devguide/logicallyairgappedvault.html)

`aws/ebs` などの AWS 管理キーと、AWS 所有キーは異なる種類のキーです。AWS 管理キーは利用者のアカウント内にあり、利用者はそのキーポリシーを変更できません。
AWS 所有キーは利用者のアカウント内にはなく、AWS サービスが所有・管理します。

> [KMS のキー種別](https://docs.aws.amazon.com/kms/latest/developerguide/concepts.html)

### 送信元の暗号化設定

送信元 EBS が `aws/ebs` で暗号化されている場合、標準ボールトおよび論理的エアギャップボールト共にクロスアカウントコピーはできません。
暗号化なしにするか、カスタマーマネージドキーで必要なポリシーを別途設定する必要があります。

### リストア時の EBS 暗号化

クロスアカウントコピーでコピー先ボールドの KMS キーで暗号化された場合、そのスナップショットからのリストアでは暗号化が必須になります。
そのため、元の EBS が暗号化なしだったとしても、AWS 管理キーかカスタマーマネージドキーでの暗号化が必要になります。

一方、前述の通り AWS 管理キーでリストアしてしまうと、そのインスタンスのバックアップがクロスアカウントコピーできなくなる問題があります。
したがって、EC2 でバックアップのクロスアカウントコピーを実施する場合、カスタマーマネージドキーの利用が事実上の必須になります。

同一リージョン内のクロスリージョンコピーであれば、AWS 管理キーで十分なので、この制限はありません。

## マルチアカウント運用のメモ

Org のバックアップポリシーで一括設定するにしてもボールド自体は個々のアカウントに必要。
Default ボールドを使うか、もしくは CloudFormation StackSets などで各アカウントにボールドや必要な IAM Role を作成する必要がある。

RAM による共有はボールド単位なので、バックアップ元のアカウントごとにクロスアカウント論理エアギャップボールドを分けることも考えられる。
共通のバックアップポリシーでは不可能なので、アカウントごとにバックアップポリシーを作成してそれぞれアタッチする必要がある。
あるいは、Org のバックアップポリシーは使わずに CloudFormation StackSets とかでバックアッププランも管理する。
